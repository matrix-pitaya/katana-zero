# KatanaZERO

一个使用 C++ 和 EasyX 编写的横版动作游戏练习项目，包含角色、敌人、场景、碰撞和子弹时间等系统。

## 开发环境

- Visual Studio 2019 或更高版本
- Windows 10 SDK
- [EasyX](https://easyx.cn/) 图形库（提供 `graphics.h`）

打开 `KatanaZERO.sln`（如果本地未生成解决方案，也可以直接打开 `KatanaZERO.vcxproj`），配置 EasyX 的头文件和库文件路径后编译。运行程序时请保持 `resource` 目录与可执行文件位于项目约定的位置。

## 目录

- `*.cpp` / `*.h`：游戏逻辑和系统代码
- `resource/`：图片、音频和字体资源
- `KatanaZERO.vcxproj`：Visual Studio 项目文件
